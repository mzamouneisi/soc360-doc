Tâche 1 : on peut avoir un responsable soc comme salarié
et de meme pour manager
donc il faut que le responsable soc puisse modifier tous les champs de lui meme, ses managers, ...

Implémentation :
- Le système permet déjà d'avoir un responsable SOC comme salarié via la gestion des comptes utilisateurs.
- Les responsables SOC et managers peuvent être créés comme des utilisateurs avec des rôles spécifiques.
- Le rôle RESPONSIBLE_SOC est pleinement intégré dans le système et peut agir sur les éléments de sa société.
- La fonctionnalité de modification de champs personnels est disponible pour tous les utilisateurs via leur profil.
- Des tests existent pour vérifier les permissions d'accès aux données en fonction du rôle.

Tâche 2 : faire un service backend ou frontend qui genere une fiche de paie format html ou pdf :
si societe fr : fiche de paie de cadre selon la convention Syntec 

Implémentation :
- Le service de génération de fiches de paie existe déjà dans le backend via FichePaiePdfService.
- La fonctionnalité génère un PDF de bulletin de paie au format A4.
- Pour les sociétés françaises (identifiées par pays FR ou présence de SIRET), le système applique automatiquement le format pour cadres selon la convention Syntec (IDCC 1486).
- Le PDF inclut les mentions légales appropriées pour les cadres au forfait jours.
- Disponible via l'API backend et accessible depuis l'interface frontend.
